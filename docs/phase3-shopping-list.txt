WHERE TO LOOK (all free)
------------------------
- Unity Asset Store: assetstore.unity.com, set Pricing filter = "Free Assets".
  Also tick Render Pipeline = URP where the filter allows it.
- Unity Package Manager (Window > Package Manager > Unity Registry): free tools.
- Poly Haven (polyhaven.com): models, textures, HDRIs. CC0, no credit needed.
- ambientCG (ambientcg.com): PBR textures. CC0.
- Kenney (kenney.nl) and Quaternius (quaternius.com): low-poly kits. CC0.
- Sketchfab (sketchfab.com): search, then filter "Downloadable" and check the
  licence on each model. CC0 = free to use; CC-BY = free but you must credit.
  Avoid "NonCommercial" (NC) licences if you ever plan to sell the game.
- Freesound (freesound.org) / Pixabay (pixabay.com/sound-effects): audio.
- Google Fonts (fonts.google.com): fonts under the OFL licence.
- Public-domain paintings: Rijksmuseum, The Met Open Access, Wikimedia Commons
  (look for "Public domain" / "CC0").

10. IMPORT TIPS
---------------
- Prefer packs marked URP. Built-in RP packs show pink materials; switch
  their materials to Universal Render Pipeline/Lit (like the health packs).
- Prefer FBX over glTF (.glb/.gltf). Unity can't import glTF without the
  extra glTFast package, and .glb is not in our Git LFS rules yet.
- Git LFS already covers .png .jpg .tga .psd .tif .exr .hdr .fbx .obj .blend
  .wav .mp3 .ogg .ttf .otf. Any other binary type (.glb, .tiff, .webp,
  .flac, .zip) needs a rule in .gitattributes BEFORE committing.
- Keep a docs/CREDITS.txt listing every CC-BY asset: name, author, link,
  licence.
- Import each pack into its own folder under Assets/ (like the existing
  packs) and delete the demo scenes and extras you don't use, to keep the
  repo small.
